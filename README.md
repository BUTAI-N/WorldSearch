# BCC VRChatワールド検索

季節・天候・明るさ・行事イベント・ロケーションで VRChat ワールドを検索できる静的サイトです。
GitHub Pages で公開され、CSV を更新するだけでサイトに反映されます。

## 仕組み

```
data/worlds.csv を編集して push
  → GitHub Actions が VRChat API からワールド名・サムネを自動取得
  → site/data.js を生成して GitHub Pages に自動デプロイ
```

検索条件の選択肢（季節・天候・明るさ・イベント・ロケーション）は CSV の内容から動的に生成されるため、CSV 側で値を追加・変更してもプログラムの修正は不要です。

## ワールドの追加・編集方法

`data/worlds.csv` を編集して main ブランチに push（または GitHub 上で直接編集）するだけです。

| 列 | 書き方 |
|---|---|
| ワールド名 | 任意（API取得失敗時のフォールバック。通常はAPIの名前が優先される） |
| URL | `wrld_xxxx...` を含む URL なら何でも可（ワールドページURL推奨） |
| 季節 | 春 / 夏 / 秋 / 冬 / 季節性なし（単一値） |
| 天候 | 晴れ / 雨 / 天候性なし（室内等） / 季節により変化 など（単一値） |
| 明るさ | 朝・昼・夕・夜・明るい・暗い・ライト調節機能付き など（単一値） |
| 行事イベント | 「数字 ラベル」形式（例: `4 お花見`）。数字は月に対応し並び順に使われる |
| ロケーション | 複数指定は「、」または「,」区切り（例: `都市、駅`）。「部屋/住居」のような「/」を含む名称は1つのタグとして扱われる |
| 説明 | 自由記述。改行を含む場合はセルを `"` で囲む |

- 1行目はタイトル行として無視されます（ヘッダーは「ワールド名」を含む行を自動検出）
- **注意**: 選択肢は表記そのままで生成されるため、表記ゆれ（例:「昼」と「昼間」）は別の選択肢になります

## ローカルでの確認

```bash
node scripts/build.mjs   # data.js を生成（Node 18 以上）
```

その後 `site/index.html` をブラウザで開くだけで動作します（サーバー不要）。

## 初回セットアップ（GitHub）

1. このリポジトリを GitHub に push
2. リポジトリの Settings → Pages → Source を「GitHub Actions」に設定
3. Actions タブから「Build and Deploy」を手動実行（以降は CSV の push で自動実行）

## 構成

```
data/worlds.csv        ワールドデータの原本（ここだけ編集する）
scripts/build.mjs      CSV解析 + VRChat API取得 + data.js生成
site/                  公開されるサイト本体
.cache/                API取得結果のキャッシュ（自動更新・コミットされる）
.github/workflows/     自動ビルド・デプロイ設定
```

## 備考

- 「ワールドページを開く」ボタンは、画面で入力した自分の VRChat User ID をオーナーとする invite インスタンス（region: jp）のインバイトページを開きます。User ID はブラウザの localStorage にのみ保存され、リポジトリやサーバーには送信されません
- VRChat API は非公式利用のため、取得は1件/秒に制限し、結果を7日間キャッシュしています
- 非公開化・削除されたワールドはカードに「非公開/削除の可能性」と表示されます
